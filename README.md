# ToDoList Tətbiqi - JDBC ilə İcra Edilmiş  

**Layihə Təsviri:** Bu layihə, istifadəçilərə şəxsi vəzifə siyahıları yaratmağa, onları redaktə etməyə, tamamlama statusunu dəyişdirməyə və silməyə imkan verən bir **To-Do List** tətbiqidir. Tətbiq, **Spring MVC** və **JDBC** istifadə edərək yaradılmışdır və PostgreSQL verilənlər bazasında saxlanılır.  

**Əsas Xüsusiyyətlər:** 
**Vəzifə Siyahısı Görüntüləmə**: İstifadəçilər vəzifələrini tamamlanmış, tamamlanmamış və ya bütün vəzifələri görmək üzrə filtrləyə bilərlər.
**Yeni Vəzifə Əlavə Etmə**: İstifadəçi yeni bir vəzifə əlavə edə bilər. 
**Vəzifə Statusunu Yeniləmə**: İstifadəçi tamamlanmış və ya tamamlanmamış vəzifənin statusunu dəyişə bilər.  


**Texnologiyalar:** 
**Spring MVC**: Backend üçün 
**JDBC**: Verilənlər bazası ilə əlaqə 
**PostgreSQL**: Verilənlər bazası
**JSP**: Dinamik HTML səhifələrinin yaradılması  

**Quraşdırma və İstifadə:** 
1. Layihəni klonlayın və Maven ilə quraşdırın.
2. PostgreSQL verilənlər bazasında uyğun cədvəl yaratmaq üçün SQL skriptlərini işlədin.
3. Tətbiqi işə salın.

    
# ToDoList App - Implemented with JDBC
**Project Description:**
This project is a **To-Do List** application that allows users to create personal task lists, edit tasks, change completion status, and delete tasks. The application is built using **Spring MVC** and **JDBC**, and it stores data in a **PostgreSQL** database.

**Key Features:**
**View Task List**: Users can filter tasks by completed or incomplete status.
**Add New Task**: Users can add new tasks to their list.
**Update Task Status**: Users can change the status of a task (mark it as completed or not).


**Technologies Used:**
**Spring MVC**: Backend framework
**JDBC**: Database connectivity
**PostgreSQL**: Database for storing tasks
**JSP**: Dynamic HTML page rendering

**Installation & Usage:**
1. Clone the repository and install dependencies via Maven.
2. Set up the PostgreSQL database with the provided SQL scripts.
3. Run the application.
